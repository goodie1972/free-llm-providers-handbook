# 03｜大厂之外还有"白给"的：商汤 sensenova、agnes、apifreellm 三个小众免费站实测

## 一、为什么突然聊"小众站"

上一篇把魔搭、硅基讲完，国内「非厂商」路线基本盘清楚了。但后台高频问题一直没变：

> 「有没有那种不怎么出名、但额度特别猛的站？」

确实有。这类站点往往不靠「卖模型」赚钱，而是用免费档做引流、做生态、做口碑，所以有时候给的额度，比大厂还猛、还干脆。

这一篇我挑了三个代表性样本，逐个核了它们 2026-08 的公开政策页和文档：

- **sensenova（商汤日日新）**：严格说商汤算大厂，但它的 Token Plan 免费玩法挺「小众」，值得单独拎出来。
- **agnes**：新加坡团队，文本 / 图像 / 视频三模态全免费、不绑卡，第三方实测可用。
- **apifreellm**：主打「永远免费」的社区沙箱，但免费层有明确限制。

但小众站有个共性——**存续不确定**。所以这篇不只吹额度，更要讲清楚：它们到底能不能放心用、怎么用才不踩雷。

> 时效声明：以下额度与政策均基于 2026-08 各官网 / 文档公开信息整理，小众站调整极频繁，具体以各自实时页面为准。

## 三、sensenova（商汤日日新）：办公场景的"免费弹药"

### 一句话定位

商汤的日日新大模型平台。它家最值得薅的不是某个聊天模型，而是 **Token Plan**——一个把「办公技能 + 轻量多模态模型」打包、公测期完全免费的调用套餐，明显冲着 Agent / 自动化办公来的。

### 免费额度速查卡

| 项目 | 内容 |
|------|------|
| 免费档 | Token Plan 公测期**完全免费** |
| 调用配额 | 每模型 **1500 次 / 5 小时**（零门槛） |
| 代表模型 | SenseNova 6.7 Flash-Lite（轻量多模态智能体）、U1.5 Lite（文生图 / 图编辑，4K，公测无水印） |
| API 格式 | 兼容 OpenAI，控制台拿 `sk-` Key |
| 开源配套 | SenseNova-Skills（办公技能，GitHub 开源）、agent_pack 一键部署 |
| 适配框架 | OpenClaw、Hermes Agent 等 |

补充：官方公布 Token Plan 日均调用已破 5000 亿次，说明这档免费额度真实在被大量使用，不是摆设。

### 上手 3 步

1. 打开 `sensenova.cn`，注册并验证账号；
2. 控制台 → **API Keys** 创建 `sk-` 开头的 Key；
3. 用 OpenAI SDK 调，base_url 以控制台文档（`platform.sensenova.cn/docs`）为准：

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 sk- Key",
    base_url="https://api.sensenova.cn/v1"   # 以控制台文档为准
)

resp = client.chat.completions.create(
    model="SenseNova-6.7-Flash-Lite",
    messages=[{"role": "user", "content": "把这段销售数据总结成 3 条结论"}],
)
print(resp.choices[0].message.content)
```

### 适合谁

- 跑自动化办公 / 数据分析 / 长链路 Agent 的人（它家模型专为「工作流」调过）；
- 需要文生图且介意水印的（U1.5 Lite 公测期 `watermark=false` 即免费无水印）；
- 想要「大厂背书 + 真免费」的新手。

### 不适合谁

- 需要超长稳定高并发生产调用的（1500 / 5h 按模型计，批量任务不够）；
- 想要闭源旗舰（GPT / Claude 一类）的。

### 踩坑

1. **「免费」是公测属性**：官方已明确 Lite / Pro 付费档「即将上线」，现在的免费随时可能缩水或转限量。当作「启动弹药」，别基于它做长期架构。
2. **配额按模型独立计**：同一档 1500 / 5h 是「每个模型」分别算，不是三家共享，规划任务时别误算。
3. **模型 ID 随版本迭代**：Flash-Lite、U1.5 Lite 这类命名会更新，调用前先去模型列表复制最新 ID。

## 四、agnes：三模态全免费、还不用绑卡

### 一句话定位

新加坡 AI Lab 出品，自称全球前十。最大亮点是：**文本、图像、视频三模态核心模型全部永久免费，且不绑卡、不限总量**。对只想「白嫖全模态」的个人开发者，这是目前罕见的一档。

### 免费额度速查卡

| 项目 | 内容 |
|------|------|
| 免费档 | 核心模型 **indefinitely 免费**（官方 FAQ 原文：免费无时间限制） |
| 限流 | 仅 RPM 限流；**无月度上限、无 Token 总量上限** |
| 文本模型 | agnes-2.0-flash（512k 上下文，支持推理 / thinking、tool calling、图输入、流式） |
| 图像模型 | agnes-image-2.1-flash（文生图 / 图编辑，最高 4K） |
| 视频模型 | agnes-video-v2.0（文生视频 / 图生视频） |
| API 地址 | `https://apihub.agnes-ai.com/v1`（OpenAI 兼容） |
| 注册 | 邮箱注册，Key 前缀 `sk-agnes-` |

第三方实测反馈：国内可直连，文本 / 图像日常可用；视频模型稳定性一般，高峰期偶尔偏慢。

### 上手 3 步

1. 打开 `platform.agnes-ai.com`，邮箱注册（国内邮箱即可），30 秒拿 Key；
2. 控制台 → 设置 → API Keys 创建（**只显示一次，先存好**）；
3. OpenAI SDK 直接调：

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-agnes-xxxx",
    base_url="https://apihub.agnes-ai.com/v1"
)

resp = client.chat.completions.create(
    model="agnes-2.0-flash",
    messages=[{"role": "user", "content": "用一句话解释什么是 agent"}],
)
print(resp.choices[0].message.content)
```

图像 / 视频模型换对应 model ID 即可（如 `agnes-image-2.1-flash`）。

### 适合谁

- 想一次性拿到文本 + 图像 + 视频三种能力的个人开发者；
- 不想绑卡、不想填支付信息的纯白嫖党；
- 做原型、Demo、低并发小工具的人。

### 不适合谁

- 对视频生成质量要求高、要稳定出片的（视频模型仍偏早期）；
- 高并发生产环境（免费层 RPM 限流，企业级需联系官方开专属通道）。

### 踩坑

1. **「免费」≠「无限速」**：虽然不限总量，但 RPM 限流是硬的，压测或批量会触发。把它当「日常额度」，别当「生产额度」。
2. **Key 只显示一次**：生成后立刻复制备份，丢了只能重置。
3. **视频模型别指望太稳**：社区反馈高峰期响应慢、偶有失败，关键场景用文本 / 图像就够了。

## 五、apifreellm：注册即得，但免费层"限制最硬"

### 一句话定位

主打「让 LLM 对所有人免费」的社区沙箱。它家确实能注册就拿 Key、永远免费，**但免费层（Community Best-Effort）限制非常明确，且不提供 OpenAI 兼容接口**——这是和前两家最大的区别。

### 免费额度速查卡

| 项目 | 内容 |
|------|------|
| 免费档 | Community Best-Effort（共享算力，Best-Effort） |
| 是否 OpenAI 兼容 | ❌ 免费层**不兼容**；仅自定义 `POST /api/v1/chat`；升级 Managed 才给 OpenAI 兼容 |
| 限制 | 日请求约 50、速率约 40s / 次、输入 ≤ 8k tokens |
| 模型 | 官方称使用 200B+ 参数模型 |
| Key | 注册即得，**永不过期** |
| 登录 | Google 登录，不绑卡 |

注意：官网「Unlimited forever / 100% Free」是品牌话术，实际免费层有清晰的每日 / 速率 / Token 上限，且「不保证可用性」。把它当测试沙箱，别当生产后端。

### 上手 3 步

1. 打开 `apifreellm.com`，Google 登录，仪表盘直接拿 API Key；
2. 免费层用自定义端点（**不是 OpenAI SDK**）：

```python
import requests

resp = requests.post(
    "https://apifreellm.com/api/v1/chat",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer 你的_KEY",
    },
    json={"message": "用一句话解释什么是 RAG"},
)
print(resp.json().get("response"))
```

3. 若要用 OpenAI 兼容 / 更高上限，需升级 Managed（消耗 credits，付费）。

### 适合谁

- 想零成本快速试一个「能对话的 API」的新手；
- 做轻量测试、Demo、学习 HTTP 调用的人；
- 不介意慢、不介意不兼容的人。

### 不适合谁

- 想直接复用 OpenAI 代码、接现有 Agent 框架的（免费层不兼容，得改请求格式）；
- 对响应速度 / 可用性有要求的（avg 11s、max 110s+、不保可用）；
- 任何生产或准生产场景。

### 踩坑

1. **免费层不是 OpenAI 兼容**：这是最大的坑。别拿 openai SDK 直接怼，会 404 / 报错；要么改自定义 POST，要么花钱升 Managed。
2. **「无限」是话术**：日限约 50、40s / 次、8k 输入——实测够「试试」，不够「用用」。
3. **可用性不保证**：Best-Effort 共享算力，高峰排队、偶发不可用，关键任务别依赖。

## 六、专题：小众站到底能不能放心用？

聊完三家，必须泼盆冷水。小众免费站有三个共性风险，用之前先想清楚：

**1. 政策说变就变（最高频）**
商汤 Token Plan 已明说付费档将至；agnes 虽称「永久免费」但新站变数大；apifreellm 直接写「可用性不保证」。免费额度本质是「获客成本」，不是「承诺」。

**2. 跑路 / 缩水风险**
小团队、靠融资或口碑撑的站，随时可能调整甚至关停。大厂至少不会一夜消失。

**3. 数据与合规**
免费层往往不签 SLA、不承诺数据驻留。把敏感业务数据喂进去，风险自担。

**怎么用才稳？三条底线：**
- 只当**兜底 / 测试 / 学习**用，别接生产主链路；
- 关键代码、产出一律**进 Git、留本地备份**，免费资源随时可能没；
- 真要生产，优先大厂免费档（01 讲的 6 家）或魔搭 / 硅基（02 讲的），小众站作补充。

## 七、所以三个站怎么选？

给你一个不用记的判断：

- **跑办公自动化 / 长任务 / 要文生图无水印** → **sensenova**。大厂背书 + 真免费 + 办公特化，性价比突出。
- **想要文本 + 图像 + 视频全白给、还不想绑卡** → **agnes**。三模态免费里目前最完整的一档。
- **只想注册就拿 Key、纯测试 / 学习 HTTP 调用** → **apifreellm**。但记住：不兼容 OpenAI、限制最硬，别上生产。

组合思路：**agnes 做日常三模态白嫖，sensenova 承接办公长任务，apifreellm 当「随手试一下」的备胎**——三家都不用花钱，错开用能把免费额度吃满。
