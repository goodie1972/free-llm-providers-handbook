# AMD 给算力、Ollama 给运行时、opencode 给终端：国外「云 + 编码」免费档一次讲透

> 上篇我们把 NVIDIA 和 OpenRouter 拉到一起对比，聊的是「谁给你模型」。这一篇换个角度：如果你想**真正跑起来**——要么自己占一块 GPU，要么本地起一个模型，要么让 AI 直接在终端里帮你改代码——这三件事对应三家完全不同的东西。AMD 给的是**算力**，Ollama 给的是**运行时**，opencode 给的是**终端外壳**。一篇讲清边界，顺带把三家免费额度全盘给你。

## 一、懒人结论（不想看长文看这句）

- **AMD Developer Cloud**：加入 AMD AI 开发者计划（免费）后，二选一领信用值——**$100 的 AMD Developer Cloud 额度**（激活后 30 天过期）或 **$50 的 Fireworks AI 额度**（90 天内兑换）。给的是**裸 GPU**（MI300X，192GB 显存），你想跑 vLLM、SGLang、微调都随你。适合「要独占一块大卡跑训练/微调/批量推理」的人。
- **Ollama**：**本地跑模型永远免费、无限量、不用账号**；云上的大模型 Free 档给「轻量用量」，**并发只有 1 个**。Pro $20/月（3 并发、50 倍用量），Max $100/月（**新注册已暂停**）。适合「日常本地主力 + 偶尔上云跑大模型」的人。
- **opencode**：**它不是模型 provider**，是一个开源的终端 AI 编程 Agent。开箱就有 **Zen 免费模型**（MiniMax M2.5 Free、Big Pickle、Nemotron 3 SuperFree 等），**不用注册任何服务、不用绑卡**就能写代码。想升级就上 **Go 订阅：首月 $5，之后 $10/月，官方称可用价值约 $60**。
- **一句话**：AMD 是**发电厂**（给你电，但电表会跑），Ollama 是**电网**（本地自发电免费，用远端要交费），opencode 是**电器**（插上就能干活，本身不发电）。三层各管一段，串起来才是完整工作流。

## 三、先划边界：这三层不是一回事

这是本篇最该记住的一张图：

```
AMD      →  算力层：给你一块 GPU，上面跑什么你自己装
Ollama   →  运行时层：把模型拉起来、暴露成 API，本地或云端都行
opencode →  应用层：一个人机交互外壳，调上面的 API 帮你改代码
```

**opencode 不提供模型**。它自己不带 GPU、不训练模型，只是个「会调 API 的终端界面」。你看到的那些"免费模型"（MiniMax M2.5 Free、Big Pickle 之类），是 opencode 团队（Zen）去找各家模型厂商谈来的额度，再分发给你用——**本质上是别人替你付了钱**。

这个区别很关键，因为它决定了三件事：

1. **稳定性**：AMD 和 Ollama 的免费档，你去官网就能看到条款；opencode Zen 的免费模型**随时可能调整或更换**，别把生产流程建在上面。
2. **可控性**：AMD 和 Ollama 你可以自建、可以换；Zen 的免费模型你只能被动接受它给什么。
3. **隐私**：AMD 和 Ollama 本地跑，代码不出你的机器；用 Zen 免费模型意味着**代码会上传到第三方**。

搞清楚这个，再看下面三家的具体额度，就不容易搞混了。

## 四、AMD：算力层的免费额度（两条路径，差别很大）

AMD 的免费额度有**两条完全不同的路径**，很多人只听说一条，这里拆开讲。

### 路径 A：加入 AI 开发者计划 → 二选一（推荐）

**免费加入，无需 AMD 硬件**。加入后你可以在会员权益页填表，从两个额度里**二选一**：

| 选项 | 额度 | 有效期 | 给你什么 | 适合 |
| --- | --- | --- | --- | --- |
| AMD Developer Cloud | **$100** | 激活后 **30 天** | 裸 MI300X GPU 访问权，vLLM/SGLang/PyTorch 随便装 | 要完全控制技术栈、跑训练/微调 |
| Fireworks AI | **$50** | 90 天内兑换，**兑换后不过期** | 托管好的 LLM API（跑在 AMD GPU 上），零运维 | 想立刻开跑，不想碰硬件 |

> 我的建议：**想学东西、想折腾选 $100 的裸 GPU；只想马上有个能用的 API 选 $50 的 Fireworks**。后者不用管部署，也不用担心「忘了关机烧光额度」。

领取流程是：注册 AMD 账号 → 填 AI 开发者计划表单 → 邮箱验证 → 进会员门户 → 在权益页选一种额度 → 等邮件拿到兑换链接/码。**不需要你有 AMD 显卡**。

### 路径 B：直接申请 25 小时免费时长（要绑卡，谨慎）

这条路径是 AMD Developer Cloud 官网单独挂的申请通道，条件和上面差很多：

- 首次申请可能拿到 **25 小时 ≈ $50** 的额度；
- **必须绑定有效信用卡**才能申请和使用；
- 有效期只有 **10 天**（比路径 A 的 30 天还短）；
- 只覆盖 MI300X GPU，**附加磁盘、对象存储、备份都不算在内**；
- 批准后约 3 个工作日到账；
- 由 AMD 全权酌情审批，你要**写清楚 GPU 使用计划**（推理/训练/微调、预期用途），写得敷衍大概率被拒；
- 申请资格限定：**独立开发者与开源项目贡献者**。

**这条路径最大的坑，官网原话就写在页面上：即使 GPU 实例处于关闭状态，仍会计费并消耗额度，直到实例被销毁为止。**

换句话说——**你以为关机了就不扣钱，其实一直在扣**。加上 10 天有效期，很多人的 25 小时是「放着放着自己蒸发掉的」。走这条路的唯一正确姿势是：**一次性把实验排好，跑完立刻销毁实例**。

### AMD 的实例规格（看看 192GB 显存有多香）

| 配置 | GPU | 显存 | vCPU | 内存 | 启动盘 | 临时盘 |
| --- | --- | --- | --- | --- | --- | --- |
| 小型 | 1× MI300X | 192 GB | 20 | 240 GB | 720 GB NVMe | 5 TB NVMe |
| 大型 | 8× MI300X | 1536 GB | 160 | 1920 GB | 1920 GB NVMe | 40 TB NVMe |

**192GB 显存是什么概念**：一台机器就能塞下 70B 级别的模型全精度推理，或者跑中小规模的 LoRA 微调——这是你本地 8GB/16GB 显卡做梦都够不到的量级。这也是 AMD 这一档真正的价值：**它不是让你省几十块 API 费，而是让你做那些「本地根本跑不了」的事**。

如果额度用完还想继续，就走按量付费，AMD 官方对接的是 **DigitalOcean** 和 **Vultr**。

## 五、Ollama：本地无限免费，云上按需（最平衡的一层）

Ollama 的免费逻辑和所有"云 API"都不一样——**它把「免费」放在了本地**。

### 套餐对照

| 套餐 | 价格 | 本地跑模型 | 云模型并发 | 云用量 |
| --- | --- | --- | --- | --- |
| Free | $0 | **无限、不用账号** | 1 个 | 轻量（light usage） |
| Pro | $20/月（年付 $200） | 无限 | 3 个 | Free 的 **50 倍** |
| Max | $100/月 | 无限 | 10 个 | Pro 的 5 倍（**新注册暂停**） |
| Team | $25/席位/月，5 席起 | 无限 | — | 含用量，共享余额 |

几个容易被忽略的细节：

- **本地运行永不收费**：下载模型、在自己机器上跑，没有账号也能用，没有 token 上限，没有并发上限。这一条比任何"每月 N 次"的免费档都实在。
- **云用量按 GPU 时间算，不是按 token**：官方明确说"我们不按固定 token 数卡你"。请求越短、命中缓存上下文越多，消耗越少。
- **双限额重置**：会话限额每 **5 小时**重置一次，周限额每 **7 天**重置一次。Free 档的"轻量"具体多少没公开数字，但并发卡死在 1——**同一时间只能跑一个云模型**，多的排队，队列满了直接拒绝。
- **模型分用量等级**：从 level 1（gpt-oss:20b 这种轻的）到 level 4（deepseek-v4-pro 这种重的），模型页面会标。挑模型前先看等级，别拿 Free 档硬刚 level 4。
- **Max 档新注册暂停中**：官方说法是云上 token 量每月翻倍、容量跟不上，为了保护老用户先停了新订阅。**Pro 和 Free 仍然开放**。
- **隐私**：官方声明 prompt 和 response **从不被记录、从不用于训练**；云模型主要托管在美国，可能路由到欧洲和新加坡；合作方是 NVIDIA Cloud Providers（NCP），要求对方做到不外传、不训练、零留存。

## 六、opencode：终端里的 Agent 外壳（Zen 免费 + Go 订阅）

opencode 是**开源的终端 AI 编程 Agent**，跑在你的 Terminal 里，能读项目、改文件、跑命令。它最大的吸引力不是技术多强，而是：**装完就能用，一分钱不花**。

### Zen：开箱即用的免费模型

启动后输入 `/models`，你会看到标注 Free 的模型，选一个回车就能开始写代码，**不需要注册任何 provider、不需要信用卡**。目前免费阵容大致有：

| 免费模型 | 备注 |
| --- | --- |
| MiniMax M2.5 Free | 免费档里综合最强，优先选它 |
| Big Pickle（GLM 4.6） | 稳定备选 |
| Hi3 Preview | 预览版，能力有波动 |
| Nemotron 3 SuperFree | NVIDIA 提供的免费档 |

**代价要说清楚**：免费模型有请求限流，**高峰期明显变慢**，能力也只够轻量任务。别指望它替你重构一个几万行的项目。另外，用 Zen 意味着**你的代码会发到第三方**——涉及公司代码、敏感仓库的，请老老实实接本地 Ollama。

### Go 订阅：$10 买到约 $60

如果你用着顺手想升级，**Go 首月 $5，之后 $10/月**。官方称因为和模型厂商有协议，$10 能换到**约 $60 的用量价值**。可用模型包括 DeepSeek V4、GLM 5.1、Qwen 3.6 Plus（官方对标 Claude Sonnet 级别）、MiniMax 2.5 / 2.7、以及小米的 Mimo。

### 省 token 的几个硬技巧（这几条最值钱）

opencode 的 TUI 里有几个设计，用好了能省一大笔：

- **`!命令` 直接跑 shell**：`!git status`、`!ls -la`、`!pnpm test`——**不花一分 token**。需要看仓库状态、跑测试，自己敲命令，别问 agent。
- **`@文件名` 精确引用**：`@src/utils/api.ts` 直接把文件塞进上下文，比让 agent 满项目乱翻快得多也便宜得多。
- **Tab 切换 Agent**：**Build**（有写权限，真改文件）和 **Plan**（只读，只分析不改）。默认 Plan——想清楚再切 Build，能少走很多弯路。
- **`/compact` 压缩上下文**：长会话跑久了，主动压一次，省 token 也提速。

## 七、上手代码（三层串起来）

**① AMD：在 MI300X 上起一个 OpenAI 兼容的推理服务**

```bash
# 在 AMD Developer Cloud 的 MI300X 实例里（已预装 ROCm + Docker）
# 1) 用 vLLM 起一个 OpenAI 兼容服务
docker run --rm -it --device=/dev/kfd --device=/dev/dri \
  --group-add video -p 8000:8000 \
  -v ~/.cache/huggingface:/root/.cache/huggingface \
  rocm/vllm:latest \
  vllm serve Qwen/Qwen3-8B --host 0.0.0.0 --port 8000

# 2) 另开终端，从本地直连（换成你实例的公网 IP）
export AMD_HOST=http://<实例公网IP>:8000/v1
curl $AMD_HOST/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"Qwen/Qwen3-8B",
       "messages":[{"role":"user","content":"用三句话解释什么是 ROCm"}]}'
```

> ⚠️ 跑完记得**销毁实例**，不是关机——关机照样计费。

**② Ollama：本地主力 + 云上兜底**

```bash
# ① 本地跑（永远免费、不耗云额度、数据不出机器）
ollama pull qwen3-coder:30b
ollama run qwen3-coder:30b "帮我看下这个函数的时间复杂度"

# ② 本地跑不动的大模型交给云（注意 Free 档并发只有 1）
ollama run deepseek-v4-pro "重构下面这段 Python，改成支持流式输出"

# ③ 一条命令起一个编码 Agent（2026 新增）
ollama launch
```

**③ opencode：把终端 Agent 接到本地 Ollama（零成本、全离线）**

```bash
# 安装（本身开源免费）
curl -fsSL https://opencode.ai/install | sh

# 进项目目录启动
cd ~/my-project && opencode

# TUI 里常用这几条：
#   /models      选模型（Zen 免费模型 or 你自己接的 provider）
#   /connect     接 provider（Ollama / Groq / Gemini / GitHub Copilot）
#   !git status  跑 shell，不花 token

# 直接把 opencode 指向本机 Ollama：完全离线、零成本

opencode run --model ollama/qwen3-coder:30b "给 utils/ 下的函数补上单元测试"
```

## 八、适合谁 / 不适合谁

- **AMD 适合**：要跑训练/微调/批量推理的独立开发者与开源贡献者；想摸清 ROCm 生态、验证 AMD 硬件适配的人；需要 192GB 显存放大模型的场景。
- **AMD 不适合**：只想调个 API 的人（用 Fireworks 或别家更省事）；**没有信用卡又不想绑卡的人**；会忘记销毁实例的人（会烧钱）；对 30 天有效期没规划的人。
- **Ollama 适合**：把本地当主力、重视代码不出机器的开发者；想一条命令起模型的人；需要离线可用的人。
- **Ollama 不适合**：机器配置很差（8GB 内存跑不动像样模型）的人；需要多并发云模型的人（Free 档只有 1）。
- **opencode 适合**：想零成本体验 AI 编程的新手；已经有 Ollama/其他 provider、想要个好用终端界面的人；愿意用 `!` 和 `@` 省 token 的人。
- **opencode 不适合**：要处理公司敏感代码还打算用 Zen 免费模型的人；期待免费档扛起大型重构的人。

## 九、踩坑 3 条

1. **AMD 最贵的一课：关机 ≠ 停费**。官方页面白纸黑字写着，实例**关闭状态下仍会计费并消耗额度，直到销毁为止**。叠加 10 天（路径 B）/ 30 天（路径 A）的有效期，很多人的额度是躺着蒸发的。正确做法：**实验排成批处理，跑完立刻 destroy**。另外路径 B 的额度**不覆盖磁盘和对象存储**，挂了额外卷是自费。
2. **Ollama 云档的"1 个并发"比你想的更卡**。Free 档同一时间只能跑一个云模型，超出的请求进队列，**队列满了直接被拒**。做批量任务时别指望它；另外用量是按 GPU 时间算的，一个忘停的长会话能把周限额吃干净。到 90% 时会发邮件提醒，别把提醒关掉。
3. **别把 opencode 当成 provider，也别把免费模型当主力**。Zen 的免费模型**可能随时调整或更换**，且高峰期明显变慢——拿它跑生产流程，哪天模型下架你就断供。正确姿势是：拿免费档试手感，**真正干活时接自己的 Ollama 或付费 provider**。另外 Zen 是第三方，敏感代码别往上发。
