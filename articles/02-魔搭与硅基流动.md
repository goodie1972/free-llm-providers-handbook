# 02｜别只盯着 API：魔搭送算力、硅基送额度，国内这两个免费入口别错过

## 一、上篇发出后，被问得最多的两个问题

上一篇把国内 6 大厂的免费档盘了一遍，后台收到最多的是这两类问题：

> 「我想自己跑个开源模型、微调一下，光有 API 不够用，有没有免费算力？」
> 「我不想一家家去注册，有没有一个地方能同时用上 DeepSeek、Qwen、GLM？」

这两个问题，恰好对应两个完全不同的东西：**一个给算力，一个给聚合**。

今天这篇就讲这两个入口：**魔搭 ModelScope** 和 **硅基流动 SiliconFlow**。

它们都不是「大模型厂商」，不自己造模型——但恰恰因为这样，它们能给你的东西，是前面 6 家给不了的。

> 额度与政策数据基于 2026-08 公开信息整理，两家调整都挺频繁，具体以各自官网为准。

## 二、先分清：它俩根本不是一类东西

这是最容易搞混的地方。很多人以为魔搭和硅基是竞品，其实**赛道都不一样**：

| | 魔搭 ModelScope | 硅基流动 SiliconFlow |
|---|---|---|
| 本质 | 模型社区 + 免费云算力 | 模型 API 聚合平台 |
| 给你什么 | CPU/GPU 算力 + 模型下载 | 一个 Key 调 100+ 开源模型 |
| 免费核心 | CPU 无限时长、GPU 36 小时 | 9B 以下模型长期免费 |
| 门槛 | 阿里云账号 | 手机号注册 |
| 典型用法 | 跑 Notebook、微调、部署 Demo | 写应用、接 Agent、批量推理 |

一句话区分：**想自己动手跑模型，去魔搭；只想调 API 省事，去硅基流动。**

当然，两者也有交集——魔搭也有 API 推理，硅基也能跑部分微调。但主战场不同，别用错地方。

## 四、魔搭 ModelScope：白给算力的「模型社区」

### 一句话定位

阿里达摩院出品，国内规模靠前的模型社区。**它最有价值的不是 API，而是免费的 Notebook 算力**——CPU 长期免费、GPU 送时长，还能高速下模型。

### 免费额度速查卡

| 资源 | 免费额度 | 说明 |
|------|----------|------|
| CPU 环境（8 核 32GB） | **不限时长** | 长期免费，挂着不下线 |
| GPU A10（24GB 显存） | **36 小时** | 教学班可申请提额 |
| API 推理 | 实名用户每日约 2000 次 | 单模型上限约 500 次/天，个别大模型更低 |
| 模型下载 | 20 万+ 模型、4 万+ 数据集 | 国内 CDN 直连，实测可达 100MB/s |
| 持久化存储 | 100 GB | Notebook 文件不丢 |

补充一个容易被忽略的隐藏福利：**AMD × 魔搭联合开发者激励计划**。完成 AMD 开发者计划注册先得 100 小时 AMD GPU，之后还能通过发技术文章、分享 Notebook、部署应用三条路径叠加，上限可到 1000 小时以上。对缺算力的人来说，这条路径比 API 额度值钱得多。

### 上手 3 步

1. 打开 `modelscope.cn`，用阿里云账号登录（没有就注册一个，不收费）；
2. 顶部导航进 **Notebook → 我的 Notebook**，选 CPU 或 GPU 环境启动；
3. 环境里预装了 PyTorch、TensorFlow 等主流框架，直接开 JupyterLab 跑代码，模型从社区高速下载即可。

如果你想直接调 API，在「账号设置」里拿 API Key，`base_url` 填魔搭的推理端点就行。

### 适合谁

- 学生 / 研究者：需要 GPU 跑实验、微调，但没卡；
- 想本地部署开源模型、先在线上试效果的人；
- 需要高速下载模型权重（国内 CDN，比 HuggingFace 快很多）的人。

### 不适合谁

- 只想要一个稳定 API 做生产调用的人——魔搭的 API 每日限额偏低，更适合调试；
- 完全不想碰代码的人——Notebook 虽然友好，本质还是开发环境。

### 踩坑

1. **GPU 时长要省着用**：36 小时看着不少，但跑一次微调可能几小时就没了。建议先用 CPU 环境把代码调试通过，再切 GPU 跑正式训练。
2. **API 每日限额是硬限制**：单模型上限约 500 次/天，个别大模型（如 DeepSeek-R1 一类）会更严格。批量任务别指望它。
3. **Notebook 环境会回收**：长时间不用环境会被释放，重要文件记得用那 100GB 持久化空间，或者推 Git。

## 五、硅基流动 SiliconFlow：一个 Key 调 100+ 开源模型

### 一句话定位

国内可直接访问的模型 API 聚合平台。**最香的一点是：9B 参数以下的开源模型长期免费**，注册还送额度，OpenAI 格式直接兼容。

### 免费额度速查卡

| 项目 | 内容 |
|------|------|
| 长期免费模型 | 9B 以下开源模型，如 Qwen2.5-7B、GLM-4-9B、DeepSeek-V2-Lite 等 |
| 新用户额度 | 注册送 2000 万 Tokens（活动政策，以官网为准） |
| 实名认证 | 完成后另有代金券奖励 |
| 免费模型限速 | 约 5–10 QPS 量级，超限会报错 |
| 模型覆盖 | 100+ 开源模型，含 DeepSeek、Qwen、GLM、Kimi 全系及图像、语音模型 |
| 接口格式 | 完全兼容 OpenAI SDK |

补充一点：它家也适配了国产芯片（昇腾），这点在国内环境里算加分项。

### 上手 3 步

1. 打开 `cloud.siliconflow.cn`，手机号注册；
2. 控制台左侧「API 密钥」新建一个 Key（`sk-` 开头，秒级生成）；
3. 直接用 OpenAI SDK 调：

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 Key",
    base_url="https://api.siliconflow.cn/v1"
)

resp = client.chat.completions.create(
    model="Qwen/Qwen2.5-7B-Instruct",   # 免费模型，零成本验证
    messages=[{"role": "user", "content": "用一句话解释什么是 RAG"}],
)
print(resp.choices[0].message.content)
```

注意模型 ID 格式是 **「组织/模型名」**，比如 `deepseek-ai/DeepSeek-V3`、`Qwen/Qwen2.5-7B-Instruct`，这点和厂商官方 API 略有不同，别直接照搬官方示例。

### 适合谁

- 第一次接触 API、想低成本跑通流程的新手；
- 做原型 / MVP，需要同时试多个开源模型的人；
- 不想一家家注册、希望一个 Key 打通的人。

### 不适合谁

- 必须用 GPT / Claude 等海外闭源模型的（硅基只做开源模型）；
- 对延迟极度敏感的实时对话场景（聚合层比厂商直连略高）；
- 高并发生产环境（免费档限速明显，生产建议走付费档）。

### 踩坑

1. **免费模型的并发限制是真的**：约 5–10 QPS，超了会报错。压测前先确认限速，别等线上炸了才发现。
2. **「组织/模型名」格式容易写错**：照抄官方模型名会 404，一定要去模型列表复制完整 ID。
3. **送的额度有活动属性**：注册送的 2000 万 Tokens 属于活动政策，随时可能调整。真正稳的是「9B 以下长期免费」这一条——**这才是硅基的核心价值，别只盯赠金。**

## 六、所以什么时候用哪个？

给你一个不用记的判断方法：

- **要动手跑模型、微调、做实验** → **魔搭**。免费 GPU 是刚需，别家给不了。
- **只想调 API、做应用、接 Agent** → **硅基流动**。一个 Key 搞定 100+ 模型，9B 以下还免费。
- **既要又要**：用魔搭调代码和微调，把跑通的模型或流程通过 API 接到硅基上做调用——这两个是互补的，不是二选一。

还有个组合用法不少人忽略：**用魔搭高速下载模型权重，本地或云端部署，再用硅基流动做开发和兜底调用。** 国内网络环境下，这套组合比直接连 HuggingFace 顺滑很多。

## 七、两个避坑

### 1. 别把「送的额度」当长期饭票

注册送的 Tokens、代金券，几乎都带活动属性和有效期。真正能长期依赖的，只有两类：

- 平台明确承诺长期免费的模型（如硅基 9B 以下、智谱 Flash 系列）；
- 长期免费的基础资源（如魔搭 CPU 不限时长）。

其余的，都当作「启动资金」来用，别基于它做长期规划。

### 2. 免费算力也要防回收

魔搭 Notebook 长期闲置会被释放，硅基的免费额度也可能调整。共通的做法是：**代码和关键文件一律进 Git，模型权重本地留一份备份。** 免费资源随时可能变，自己的产出不能跟着一起没。
