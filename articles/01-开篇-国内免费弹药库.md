# 01 开篇｜别只盯着一个大模型：先把国内免费弹药库盘明白

## 一、我怎么从「每月几百」变成「几乎零成本」

三个月前，我跟你一样：想用 AI 写周报、改文案、跑点数据、做个小工具，结果每次都被付费墙拦住。月费一开就是几百，API 按 token 计费，模型名字一大堆，还没弄明白自己到底要什么，先交了一笔学费。

后来我花了点时间，把这些「免费」资源一个个试过来——国内大厂的、海外平台的、还有能自己 Docker 一键拉起来的聚合代理。试完一个感受：**认真薅，普通人日常用 AI，几乎可以做到零成本**。

但这个「免费」二字，水很深。很多人一听到「免费 LLM」就兴奋，一用发现要绑卡、有额度、还限速。问题出在：大家嘴里的「免费」根本不是一回事。

## 二、先把「免费」这个词讲清楚

**本系列只认三种「真免费」，并且每一篇都标清楚它属于哪一种：**

1. **永久免费层（Free Tier）**：不用绑卡，长期可用，只是限速 / 限额度。例如硅基流动 9B 以下开源模型永久免费。
2. **新用户试用额度**：注册送一笔 token / 代金券，有有效期，能白嫖一阵但不是永远。例如 DeepSeek 新用户送 500 万 tokens（30 天）。
3. **本地推理**：在自己电脑跑开源模型，永远免费，但吃显卡。Ollama 本地部署就属于这一类。

凡是「要先充钱才能用」的，本系列不叫它免费，只当省钱备选。

## 四、逐家拆解

### 1. 智谱 GLM（Zhipu AI）

- **一句话定位**：国产综合实力靠前，中文与 agent 能力强，Flash 系列免费力度相当大。
- **免费额度速查卡**：新用户送 2000 万 Tokens；GLM-4.7-Flash 等多款 Flash 模型**永久免费**；需注册登录。
- **上手 3 步**：
  1. 打开 `open.bigmodel.cn` 注册；
  2. 控制台「API 密钥」新建一个 key；
  3. 改 `base_url=https://open.bigmodel.cn/api/paas/v4`，模型填 `glm-4.7-flash`，零成本跑通。
- **适合谁**：中文写作、搭 agent、需要稳定国产大模型的人。
- **不适合谁**：要极致推理性价比的（看 DeepSeek）。
- **踩坑**：Flash 模型能力强但非旗舰，复杂任务换 GLM-5 系列要付费；额度按 tokens 计，批量脚本注意限速。

---

### 2. 通义千问（阿里 Tongyi / Qwen）

- **一句话定位**：开源生态很活跃的国产后盾，Qwen 全系开源可本地部署，网页端核心功能免费。
- **免费额度速查卡**：新用户 1000 万+ tokens；网页端核心功能**永久免费**；与云百炼共用底层、入口不同。
- **上手 3 步**：
  1. 打开 `dashscope.aliyun.com` 用阿里云账号登录；
  2. 开通模型服务，拿到 DashScope API Key；
  3. 用 OpenAI 兼容接口，`base_url=https://dashscope.aliyun.com/compatible-mode/v1`，模型填 `qwen-plus` 或 `qwen-max`（免费档）。
- **适合谁**：想玩开源模型、多模态、自建应用的人。
- **不适合谁**：不想绑定阿里云账号体系的。
- **踩坑**：dashscope 与云百炼（bailian）是同一能力两套入口，别重复计数；免费档模型与付费旗舰有差距。

---

### 3. DeepSeek（深度求索）

- **一句话定位**：API 价格处于低位、推理与代码强，国产里性价比突出的一款。
- **免费额度速查卡**：新用户送 500 万 tokens（30 天，**无需绑卡**）；网页对话免费；API 按量计费也便宜。
- **上手 3 步**：
  1. 打开 `platform.deepseek.com` 注册（不用绑卡）；
  2. 充值或先用赠送额度，建 API Key；
  3. `base_url=https://api.deepseek.com/v1`，模型 `deepseek-chat` / `deepseek-reasoner`。
- **适合谁**：写代码、做推理、对成本敏感的个人与团队。
- **不适合谁**：要超长上下文（看 Kimi）或重度多模态的。
- **踩坑**：国内访问偶有波动；30 天额度过期后需充值，但单价极低，真用也就几块钱。

---

### 4. Kimi（月之暗面 Moonshot AI）

- **一句话定位**：256K 超长上下文，优势突出，长文档摘要、超长对话场景几乎无对手。
- **免费额度速查卡**：新用户约 15 元代金券（**永久**）；网页每日无限对话；Kimi K2 Coding 强。
- **上手 3 步**：
  1. 打开 `platform.moonshot.cn` 注册；
  2. 建 API Key，网页端直接对话免费；
  3. OpenAI 兼容接口，`base_url=https://api.moonshot.cn/v1`，模型 `moonshot-v1-8k/32k/128k`。
- **适合谁**：律师/研究员/运营等要吞长文档的人；长对话项目。
- **不适合谁**：要极致性价比推理的（看 DeepSeek）。
- **踩坑**：长上下文虽爽，但按 token 计，超长输入消耗快；代金券永久但额度有限。

---

### 5. 豆包（字节跳动）

- **一句话定位**：字节系国民级 AI，日常对话免费，还顺带送图像（Seedream）与视频（Seedance）生成。
- **免费额度速查卡**：火山方舟新用户免费额度；网页对话免费；API 需实名。
- **上手 3 步**：
  1. 打开 `doubao.com` 直接网页对话（免费）；
  2. 开发者走火山引擎方舟 `console.volcengine.com` 领免费额度；
  3. 方舟 API 兼容 OpenAI，模型填 `doubao-pro` 等。
- **适合谁**：日常问答、内容创作、要白嫖图/视频生成的人。
- **不适合谁**：要严肃 agent / 长上下文推理的（看智谱 / Kimi）。
- **踩坑**：豆包网页与火山方舟是两套，开发者额度在方舟；API 实名门槛略高。

---

### 6. 云百炼（阿里云百炼 Bailian）

- **一句话定位**：阿里云上的「通义能力商店」，和通义千问同一套模型，但按「每模型赠送」拆得更细。
- **免费额度速查卡**：新人每模型 100 万 tokens；产品页公开。
- **上手 3 步**：
  1. 打开 `bailian.console.aliyun.com` 用阿里云登录；
  2. 模型广场选模型，领免费试用额度；
  3. 走百炼 SDK / OpenAI 兼容接口调用。
- **适合谁**：已在阿里云体系、要做企业级应用集成的开发者。
- **不适合谁**：不想绑阿里云、只想轻量试用的（直接去通义千问更省事）。
- **踩坑**：与通义千问同一能力两套入口，别重复建号；额度按模型分，单模型 100 万看着少但能攒。

## 五、按场景怎么选：4 句话拍板

看完 6 家，最后给一个不用记的拍板逻辑。下次有人问你「哪个免费模型适合我」，按这 4 句走就行：

1. **要吞超长文档**（合同、论文、财报）→ **Kimi**。256K 上下文是它的护城河。
2. **主要写代码、做推理** → **DeepSeek**。单价低、代码能力强，额度用完了真充值也就几块钱。
3. **已在阿里云 / 字节体系，要企业级集成** → **云百炼** 或 **豆包方舟**。有 SLA、生态打通。
4. **以上都不是，就想找个稳定好用的** → **智谱 GLM**。综合表现均衡，Flash 系列还长期免费。

一句话总结：**长文本找 Kimi，写代码找 DeepSeek，做产品上百炼/豆包，兜底用智谱。**

## 六、第一个避坑：免费 ≠ 无限制

刚开始我也天真地以为「免费 = 随便用」。踩了几次才明白三件事：

- **限速是真限速**：免费档普遍 30 RPM 上下，写个批量脚本分分钟被 429 打断。
- **额度会变**：平台说改就改，去年慷慨的今年可能砍一半。所以每篇我都标「核验日期」。
- **小众站会跑路**：后面会讲到 agnes、apifree 这类小站，今天能用要防明天关。真要依赖，务必本地存好、及时迁走。
