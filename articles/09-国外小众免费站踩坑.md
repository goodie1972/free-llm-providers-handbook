# 三个号称"免费"的小众站，我全踩了一遍坑：Peezy / OrcaRouter / B.AI 实测

> 时效声明：本文数据核实于 **2026-09-06**。小众站的免费政策变动极快（写这篇的前三天，B.AI 刚好把最香的那两个模型改成收费了），你看到时请以官网实时页面为准。

## 一、为什么又去折腾这些小众站

先交代背景。我之前把主流的免费额度薅得差不多了——OpenRouter 的 50 次/天、Groq 的分钟限额、硅基和智谱的注册赠送，日常写着写着就见底。尤其是跑 Agent 类的活儿，那玩意儿特别烧 token，一个任务下来几千上万，主流那点免费额度根本撑不住。

所以最近我在各种群里格外留意那些「小众免费站」。这篇文章里的三家，就是这阵子被推荐得最多的：**Peezy、OrcaRouter、B.AI**。

三家我都注册跑了，结论先放这儿：**它们都号称免费，但没有一家是"你想象中的那种免费"**。每家都有一个"但是"，而且这个"但是"还挺关键。我把踩过的坑原样写出来，省得你再踩一遍。

---

## 二、先上结论：三家速查总表

| 平台 | 定位 | 真正免费的部分 | 要花钱的地方 | 最大的坑 | 适合谁 |
|---|---|---|---|---|---|
| **Peezy** | 聚合网关（双协议） | 4~7 款模型，5 小时滚动额度 | 超出免费额度的部分 | 5 小时滚动窗口，不能脉冲式用完 | 想白嫖 DeepSeek/代码模型的个人开发者 |
| **OrcaRouter** | AI 网关 / 路由器 | **只免"过路费"**（0% 加价）+ 轮换的免费模型 | **token 按上游原价付**，跑付费模型得先充值 | "Free Forever"极易被误读成"免费 token" | 本来就在直连 OpenAI/Anthropic、想省 5–20% 的人 |
| **B.AI** | Web3 背景模型聚合 | 4 款模型零成本（原 6 款） | 9/3 起 DeepSeek 系列改为分级收费 | 需要梯子；免费阵容正在缩水 | 有梯子、想临时大额调用的人 |

一句话总结我的体感：**Peezy 是真给额度，OrcaRouter 是帮你省钱，B.AI 是先给甜头再慢慢收网。**

---

## 三、Peezy：额度给得最实在，但那个"5 小时滚动窗口"能治好你的急性子

### 3.1 它是什么

Peezy 是个 AI 聚合网关，最大的优点是**同时兼容 OpenAI 和 Anthropic 两套协议**。这一点比什么都重要——你原来写给 OpenAI 的代码，只改一个 `base_url`，其他一个字都不用动；写给 Claude 的代码同理。

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的_Peezy_Key",
    base_url="https://api.p0.systems/api/agents/v1"   # 只改这一行
)

resp = client.chat.completions.create(
    model="deepseek-v4-flash-0731",
    messages=[{"role": "user", "content": "用 Python 写个二分查找"}]
)
print(resp.choices[0].message.content)
```

如果要走 Anthropic 格式，端点换成 `https://api.p0.systems/api/agents/v1/messages` 就行。

注册入口在 `peezy.p0.systems`，支持邮箱和 GitHub 登录，不用绑卡，注册完就能用。

### 3.2 免费额度（5 小时窗口）

| 模型 | 每 5 小时额度 |
|---|---|
| DeepSeek V4 Flash 0731 | 500 次 |
| Poolside Laguna S 2.1 | 500 次 |
| Ling 3.0 Flash | 500 次 |
| Cohere North Mini Code | 500 次 |
| MiniMax M3 | 200 次 |
| MiMo V2.5 | 免费（以控制台显示为准） |
| Grok 4.3 | 10 次 |
| GLM-5.2 | 总共 15,000 token，每天上限 5,000，用完即止 |

⚠️ 顺带说一句：我在不同来源看到的数字**对不上**（MiniMax M3 有说 200 次有说 3500 次，MiMo V2.5 有说 99 次有说"以控制台为准"）。这本身就说明一件事——**它的额度是在动态调整的**，别把任何一张表当成长期承诺。

### 3.3 坑一：5 小时滚动窗口，专治急性子

这是我最想吐槽、也最值得讲的一点。

我们习惯了"每天零点重置"的额度机制，所以总觉得：今天把额度打满，睡一觉明天又是一条好汉。Peezy **不是**这么玩的，它用的是 **5 小时滚动窗口（Rolling Window）**：

> 你上午 10 点发出的每一次请求，要等到下午 15 点才会释放配额。计数器**永远不会在某个时刻全部归零**，而是持续滑动。

实际影响是什么？

- **匀速调用的人**：几乎无感，5 小时刚好走完一轮，无缝衔接。
- **想十分钟打爆额度然后干等的人**：后面整整五个小时直接挂零。

想用"零点前半小时冲一波、零点后再冲一波"这种老套路？在这完全行不通。平台用这套机制无声地表达了态度：**欢迎真实开发者，不欢迎薅完就跑的脚本。**

客观说，这对认真做项目的人是利好——你不用跟批量脚本抢资源，稳定性反而更有保障。但如果你习惯了脉冲式使用，第一次撞上会觉得"怎么额度不刷新了"。

### 3.4 坑二：额度是"估算值"，不是实打实的次数

官方标称的 500 次是估算。实际消耗受**提示词长度、输出长度、是否调用工具**这些因素影响。

我自己踩过：拿它跑一个带长 system prompt 的多轮对话，每轮都挂几千 token 的上下文，实际能调用的次数大概只有标称的一半出头。单轮问答没问题，长对话要心里有数。

### 3.5 坑三：创建 Key 时，那个输入框千万别乱填

这个坑把我坑得最莫名其妙，必须单独拎出来说。

登录后进 `CONNECT` 页面，点 `CREATE PEEZY KEY`。页面上会有一个**输入框**——很多人（包括我）习惯性地以为"总得填点什么"，就随手输了点东西再点下面的按钮，结果系统提示：

```
没这个 code / 已过期
```

我当时的反应是"哦，创建失败了"，差点直接关页面走人。**其实不是失败，是别乱填——直接点按钮就行。** 那个输入框是给你填邀请码/兑换码用的，留空即可。

另外两个小提醒：
- **API Key 只展示一次**，生成后必须马上复制保存，关掉就找不回来了。
- 页面**全英文**，看不懂的挂个翻译插件。

### 3.6 其他小毛病

响应速度确实不如国内平台，得有点耐心；偶尔会遇到 429，跟所有免费 API 一样，属于正常现象，多重试几次或者换个渠道就好。

**小结**：Peezy 是这三家里**唯一真给额度**的，不用绑卡、注册即用。它的坑不在"要钱"，而在"机制"——你得接受它的节奏。

## 四、OrcaRouter：它免的是"过路费"，不是"油钱"

### 4.1 它到底是什么

OrcaRouter 不是模型 provider，是个 **AI 网关 / LLM 路由器**。它做的事是：给你一个 OpenAI 兼容端点，背后接了 **200+ 模型、40+ 供应商**，每次请求进来它先给 prompt 打分（官方称 <1ms），然后自动路由到最合适的模型。

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.orcarouter.ai/v1",
    api_key="你的_OrcaRouter_Key",
)

resp = client.chat.completions.create(
    model="orcarouter/auto",   # 让它自动评分 + 路由
    messages=[{"role": "user", "content": "..."}],
)
```

它的卖点写得很响亮：**Hacker 计划 "Free Forever"、0% token markup、3 个 API key、无需信用卡。**

### 4.2 那个"但是"：0% 加价 ≠ 0 成本

这是全文最需要划重点的一句：

> **OrcaRouter 免的是"过路费"（网关通常加的 5–20% 加价），不是"油钱"（token 本身）。**

它是**零加价（zero markup）**，不是**零成本（zero cost）**。token 按上游 provider 的官方原价收——OpenAI 收你多少，它就收你多少，一分不多，但也一分不少。

所以：

| 你想做的事 | 要不要花钱 |
|---|---|
| 用网关路由、故障转移、看日志 | **免费** |
| 调那批轮换的免费开源模型（如 `qwen3.8-27b-free`） | **免费** |
| 调 GPT-5.6 Sol / Claude Opus / Grok 这些付费模型 | **照原价付，而且得先充值** |

我就卡在这儿了。兴冲冲注册完、拿到 key、改好 `base_url`，一跑发现余额不足——**想用付费模型，得先往钱包里充钱，最低 $1 起**。钱不多，但这跟我理解的"免费"是两回事。

### 4.3 那它到底能省什么？

省的是这两块：

1. **网关加价**：同行普遍加 5–20%，它加 0%。如果你本来就必须直连 OpenAI/Anthropic，走它能省下这笔。
2. **自适应路由**：把简单请求自动路由到便宜的开源模型，复杂请求才上 frontier 模型。官方称这套能降 40%+ 推理成本，且质量损失 <1%。

所以它的正确定位是：**给已经在花钱调 API 的人省钱的工具**，不是给想白嫖的人送额度的慈善机构。

### 4.4 真想白嫖怎么办？

两条路，但都不太稳：

- **用它轮换的免费模型**：每 token $0，随着新的开源权重模型上线会持续轮换。但数量有限，且随时可能换掉。
- **去 offers 页抢兑换券**：官方有个免费额度发放页，会放兑换券、黑客松启动额度之类的福利。**但**：券会领完（我去看的时候已经挂着"兌換券已領完""已領取 140/140"），而且**部分福利需要绑卡**（比如 Grok 4.5 的活动就明确标注"需綁卡"）。

**小结**：OrcaRouter 是个好工具，但"Free Forever"这四个字极具误导性。看到"免费"先问一句：**免的到底是什么？**

## 五、B.AI：免费额度最猛，但我眼看着它开始收网了

### 5.1 它是什么

B.AI（也叫 Bank of AI，备用域名 `bankofai.io`，聊天入口 `chat.b.ai`），2026 年 5 月上线，运营主体是新加坡的 BAI Inc.，创办人是币圈的孙宇晨。定位是「AI Agent 的基础金融设施」——把模型聚合和 Web3 支付（x402 协议）、链上身份（8004 协议）揉在一起。

产品线挺全：网页聊天 B.AI Chat、统一 API、Agent 产品 BAIclaw、编程工具 BAI code。

数据确实猛：开放免费后**日均 token 吞吐突破 1.33 万亿**，15 天累计 8.19 万亿，新增 API 用户 22 万+，总用户突破 230 万。

### 5.2 最初的免费阵容（6 款，不限量）

| 模型 | 现在的状态 |
|---|---|
| DeepSeek-V4-Flash | ⚠️ **9/3 起改为分级收费** |
| DeepSeek-V4-Flash-Vision-Exp | ⚠️ **9/3 起改为分级收费** |
| GLM-5.3-Flash (Ox Alpha) | ✅ 仍零成本 |
| Qwen3.8-Flash | ✅ 仍零成本 |
| 腾讯 Hy3 | ✅ 仍零成本 |
| 小米 MiMo-V2.5 | ✅ 仍零成本 |

### 5.3 坑一：我眼看着它开始收费了

这是最值得警惕的一点，也是"限时免费"四个字的真实含义。

**2026 年 9 月 3 日**，就在我调研的这几天，B.AI 对最受欢迎的两款 DeepSeek 模型启用了分级定价：

- 高峰期：**5 折**
- 低谷期：低至标准价的 **25%**

注意，不是"打五折"，是"从免费改成收费，高峰期给你打个五折"。好在 GLM-5.3-Flash、Qwen3.8-Flash、腾讯 Hy3、小米 MiMo-V2.5 这四款目前还是零成本，但**免费阵容从 6 款缩到 4 款，只用了不到一周**。

这给所有薅羊毛的人上了一课：**免费聚合平台的策略随时会变**，降配额、改规则、直接收费，在 AI 行业已经有太多先例。

### 5.4 坑二：需要梯子

这个不用多说，B.AI 是海外平台，**国内需要科学上网**。它的"智能路由"依赖网络质量，速度波动会比较明显。

### 5.5 坑三：条款里的那几条，要看清

B.AI 主打"匿名"卖点——支持 Web3 钱包登录，官方隐私政策明确说**钱包地址、私钥、链上记录不属于收集的个人信息**。听起来很美好。但同一份隐私政策里也白纸黑字写着：

- 会**收集邮箱地址**（用于账号通知、结算提醒）；
- 会用 **cookie 记录你的会话信息和 API 使用偏好**；
- 会**使用第三方服务商**做站点追踪分析，以了解用户对站点的使用情况。

另外，已有实测文明确提醒两点：**充值积分不退**、**对话会被记录存储**。

我的建议很朴素：**别往这类小众站传敏感内容**——合同、客户名单、商业报价、个人隐私，一律先脱敏。

### 5.6 坑四：Web3 背景带来的额外变量

它有"限时 1:1 充值匹配"（充多少送等额，上限 $100 之类）、链上身份、加密货币支付通道这些玩法。对币圈用户是加分，对只想安安静静调个 API 的普通开发者来说，多了一层**波动性和政策风险**。参与充值活动前，规则务必逐条看清。

**小结**：B.AI 的免费额度是三家里最猛的，但它的"免费"是有保质期的，而且已经开始兑现了。

## 六、我的用法：三家怎么配合着薅

踩完坑，说说我现在的实际分层策略：

1. **日常轻量活儿 → Peezy**。写脚本、跑原型、学习练手，DeepSeek V4 Flash 的 500 次/5 小时完全够用。关键是**保持匀速**，别脉冲。
2. **已经在花钱调 API 的部分 → OrcaRouter**。把 `base_url` 指过去，用 `orcarouter/auto` 让它自己路由，省掉网关加价那部分。但别指望它给你免费 token。
3. **临时需要大额/多模型对比 → B.AI（有梯子的前提下）**。用那 4 款零成本模型，且做好"随时会变"的心理准备。

**三条通用纪律**（都是踩出来的）：

- **别 All in 任何一家小众站**。B.AI 三天前还在免费列表里的模型，今天就开始收费了。永远备好切换方案。
- **看到"免费"先问免的是什么**。是免额度？免路由费？还是限时才免？这三个答案对应完全不同的预期。
- **敏感数据绝不上传**。小众站的数据留存策略不透明，脱敏是底线。

## 结尾：一句真心的提醒

折腾完这三家，我最大的收获不是多薅到了多少额度，而是养成了一个习惯：

**以后再看到"免费"两个字，我会先问一句——你免的到底是什么？**

Peezy 免的是额度，但用滚动窗口管着你；OrcaRouter 免的是过路费，油钱照付；B.AI 免的是当下的额度，但随时可能收回去。

三种"免费"，三种完全不同的预期管理。搞清楚这一点，比多薅几千次调用重要得多。

反正这三家我现在都还留着——毕竟**免费的，不用白不用**。但每一家我都留了后路，也都没放敏感数据。你要是也在薅，建议照这个心态来：**薅得开心，但别把身家性命押上去。**
