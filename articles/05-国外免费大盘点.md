# 不出国也能白嫖全球算力：国外 4 大免费大模型入口，一篇盘清

上一篇（04）我们用国内免费额度搭起了一个能跑一年的个人 AI 工作流。但凡认真用过的人都会发现一个天花板：**国内免费档的 RPM（每分钟请求数）和上下文长度，撑得起个人把玩，撑不起「想怎么试就怎么试」**。

这一辑（第二辑·国外免费档）我们打开国门外的弹药库。先说结论：**2026 年国外依然有一批「免信用卡、永久免费层」的大模型 API**，其中 Google Gemini 的免费额度甚至比很多付费档都大方。但「免费」这个词在海外语境里至少有三种含义，不先界定清楚，你就很容易被「Free」两个字带沟里。

---

## 〇、先界定：海外说的「Free」是哪三种？

读任何一篇英文「free LLM」盘点，先问自己它在说哪一种：

1. **永久免费层（Free Tier / Permanent Free）**：不用绑卡、没有过期日，额度有限但长期可用。✅ 本文主角。
2. **试用额度（Trial Credit）**：注册送 $5 之类，但 **3 个月或 30 天就过期**，到期必须绑卡付费。代表：OpenAI、Anthropic 的新账号额度。**不算真免费，本文不列为主角**。
3. **本地推理（Local / Self-host）**：Ollama 把模型跑在你自己电脑上，零 API 成本、零额度限制，但吃你的显卡和电费。属于「免费」的另一种形态，本辑后面会单讲。

本文聚焦第 1 种——**真·免信用卡、可长期白嫖的 API 免费层**，挑出最值得国人用的 4 个：Gemini、Groq、Mistral、Hugging Face。

## 二、逐家单测

下面每家都按同一套模块讲：**一句话定位 → 免费额度速查卡 → 上手 3 步 → 适合谁/不适合谁 → 踩坑 3 条**。

### 2.1 Gemini（Google AI Studio）⭐ 国外免费档综合第一

**★ 一句话定位**：免信用卡、给最强模型、还送 1M 上下文和多模态——2026 年个人开发者最稳的免费 API。

**★ 免费额度速查卡**

| 字段 | 内容 |
|------|------|
| 入口 | aistudio.google.com（用 Google 账号登录） |
| 免费模型 | Gemini 2.5 Flash（推荐）/ 2.5 Pro / 2.5 Flash-Lite |
| 速率 | Flash 约 15 RPM、1500 RPD；Pro 约 5 RPM、100 RPD |
| 上下文 | 100 万 token（1M） |
| 多模态 | ✅ 文本 / 图片 / 音频 / 视频 / PDF |
| 绑卡 | ❌ 不需要 |
| 兼容 | ✅ OpenAI 兼容 base_url |
| 主要限制 | RPM 偏紧、免费档 prompt 可能用于产品改进 |

**★ 上手 3 步**

1. 打开 aistudio.google.com → 左侧 "Get API Key" → 创建 Key（即时生成）。
2. 记下 Key，设置环境变量：

```bash
export GEMINI_API_KEY="你的Gemini_Key"
```

3. 用 OpenAI 兼容客户端调用（base_url 用 Google 的专用地址）：

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的Gemini_Key",
    base_url="https://generativelanguage.googleapis.com/v1beta/openai",
)
resp = client.chat.completions.create(
    model="gemini-2.5-flash",
    messages=[{"role": "user", "content": "用三句话解释什么是向量数据库"}],
)
print(resp.choices[0].message.content)
```

**★ 适合谁 / 不适合谁**
- 适合：长文分析、多模态理解、个人项目、原型验证。
- 不适合：对数据隐私零容忍的生产服务（免费档 prompt 可能用于训练改进）；高并发线上服务（RPM 太紧）。

**★ 踩坑 3 条 + 替代**
1. **RPM 很紧**：并发一高就 429。替代：把重活路由到 Groq，Gemini 专攻长上下文。
2. **额度历史上砍过**：2025-12 曾一夜削减 50%–80%。替代：关键业务留好付费降级通道。
3. **区域与数据条款**：EEA/UK/瑞士以外的数据可能被用于改进。替代：敏感数据走本地推理（Ollama）。

> 时效声明：Gemini 免费阵容与额度截至 2026-09-01 核验，Google 按项目（非按 Key）计配额，且随时可能调整，以 ai.google.dev 官方文档为准。

### 2.2 Groq（速度怪兽）⭐ 要快就它

**★ 一句话定位**：用自研 LPU 芯片把推理速度卷到毫秒级，免费层还挺大方——做实时交互的第一选择。

**★ 免费额度速查卡**

| 字段 | 内容 |
|------|------|
| 入口 | console.groq.com（Google/GitHub 登录） |
| 免费模型 | Llama 3.3 70B、DeepSeek-R1、Llama 4 Scout、Mixtral 等 |
| 速率 | 约 30 RPM、每日约 1.4 万次（小模型）；大模型每日约 1000 次 |
| 上下文 | 最高 128K |
| 多模态 | 主要为文本（部分视觉模型陆续上） |
| 绑卡 | ❌ 不需要 |
| 兼容 | ✅ OpenAI 兼容 |
| 主要限制 | 免费档额度小、不适合流量峰值 |

**★ 上手 3 步**

1. console.groq.com → API Keys → 生成 Key。
2. 设置环境变量：

```bash
export GROQ_API_KEY="gsk_xxxxxxxxxxxx"
```

3. OpenAI 客户端直连（base_url 用 Groq 的）：

```python
from openai import OpenAI

client = OpenAI(
    api_key="gsk_xxxxxxxxxxxx",
    base_url="https://api.groq.com/openai/v1",
)
resp = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[{"role": "user", "content": "用 Python 写一个快排"}],
)
print(resp.choices[0].message.content)
```

**★ 适合谁 / 不适合谁**
- 适合：聊天机器人、实时补全、Agent 工具调用、对延迟敏感的一切。
- 不适合：长文档一次性分析（上下文和额度都不如 Gemini）；流量陡增的生产（免费层会被限流）。

**★ 踩坑 3 条 + 替代**
1. **大模型每日限量**：70B 级模型免费档每天约 1000 次，刷多了就 429。替代：轻量任务换 8B 小模型（每日 1.4 万次）。
2. **峰值被限流**：免费请求优先级低。替代：把 Groq 当「快通道」，付费档当「稳通道」做 fallback。
3. **模型会轮换**：Groq 常上线下线模型。替代：代码里用模型名常量，便于统一切换。

> 时效声明：Groq 免费模型与额度截至 2026-09-01 核验，以 console.groq.com 官方文档为准。

### 2.3 Mistral（欧洲选手）⭐ 轻量 + 合规

**★ 一句话定位**：欧洲出品、开源血统，免费层不惊艳但够轻量场景用，且自带「欧洲数据合规」叙事。

**★ 免费额度速查卡**

| 字段 | 内容 |
|------|------|
| 入口 | chat.mistral.ai（Le Chat 网页）/ console.mistral.ai（la Plateforme API） |
| 免费模型 | Le Chat 网页可免费用较强模型；API 免费层主要是 Mistral 7B / Small 级 |
| 速率 | API 免费层约 1 req/s |
| 上下文 | 32K–128K（依模型） |
| 多模态 | 部分模型支持 |
| 绑卡 | Le Chat 网页不需要；la Plateforme API 试用需注册 |
| 兼容 | ✅ OpenAI 兼容 |
| 主要限制 | 免费 API 层模型有限、速率严 |

**★ 上手 3 步**

1. console.mistral.ai → 注册 → API Keys 生成 Key。
2. 设置环境变量：

```bash
export MISTRAL_API_KEY="你的Mistral_Key"
```

3. OpenAI 客户端直连：

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的Mistral_Key",
    base_url="https://api.mistral.ai/v1",
)
resp = client.chat.completions.create(
    model="mistral-small-latest",
    messages=[{"role": "user", "content": "把这句话翻成法语：今天天气真好"}],
)
print(resp.choices[0].message.content)
```

**★ 适合谁 / 不适合谁**
- 适合：轻量翻译/摘要、欧洲业务合规诉求、想支持开源生态。
- 不适合：重度免费依赖（API 免费层偏紧）； multimodal 重度场景（模型支持有限）。

**★ 踩坑 3 条 + 替代**
1. **免费 API 层太薄**：想用强模型基本要付费。替代：纯聊天用 Le Chat 网页免费版更香。
2. **1 req/s 很慢**：批量任务会卡。替代：Groq 跑批量，Mistral 只做轻量点缀。
3. **模型名常变**：`latest` 后缀会随版本跳。替代：锁定具体版本号（如 `mistral-small-2506`）保稳定。

> 时效声明：Mistral 免费层与模型名截至 2026-09-01 核验，以 docs.mistral.ai 官方文档为准。

### 2.4 Hugging Face Inference ⭐ 开源模型的海洋

**★ 一句话定位**：20 万+ 开源模型随便试，免费档是「模型探索/原型验证」的最佳沙盒，但别指望它快。

**★ 免费额度速查卡**

| 字段 | 内容 |
|------|------|
| 入口 | huggingface.co → 模型页 "Deploy" / Inference API |
| 免费模型 | 20 万+ 开源模型，免费档限小模型（<10B 参数） |
| 速率 | 速率受限（免费 Serverless 约每小时数十次量级），冷启动 30s+ |
| 上下文 | 依模型 |
| 多模态 | 依模型（文本/图像/音频都有） |
| 绑卡 | ❌ 不需要 |
| 兼容 | ✅ Endpoints 提供 OpenAI 兼容 |
| 主要限制 | 冷启动慢、延迟不可预测、大模型需付费/按 GPU 计费 |

**★ 上手 3 步**

1. huggingface.co → Settings → Access Tokens 生成 Key。
2. 设置环境变量：

```bash
export HF_API_KEY="hf_xxxxxxxxxxxx"
```

3. 调用 Serverless Inference（注意 base_url 不同于常规聊天）：

```python
import requests

API_URL = "https://api-inference.huggingface.co/models/mistralai/Mistral-7B-Instruct-v0.3"
headers = {"Authorization": f"Bearer hf_xxxxxxxxxxxx"}

resp = requests.post(API_URL, headers=headers, json={
    "inputs": "用一句话解释 Transformer 的注意力机制",
})
print(resp.json())
```

**★ 适合谁 / 不适合谁**
- 适合：试新模型、跑非主流开源模型、做研究原型。
- 不适合：对延迟敏感的生产（冷启动 30s+，共享算力排队）；大模型推理（免费档基本只够小模型）。

**★ 踩坑 3 条 + 替代**
1. **冷启动劝退**：首次调用可能等 30 秒以上。替代：高频模型用 Groq/Mistral 这类常驻服务。
2. **免费档只够小模型**：想跑 70B 得付费或本地。替代：Ollama 本地跑大模型零成本。
3. **API 形态不统一**：Serverless 与 Endpoints 的调用方式不同。替代：统一抽象一层 client，避免业务代码耦合 HF 细节。

> 时效声明：Hugging Face Inference 免费档与限额截至 2026-09-01 核验，以 huggingface.co 官方文档为准。

## 三、选型决策树（照着选不踩坑）

```
├─ 长文档 / 多模态 / 不想绑卡 ──────────► Gemini

├─ 想逛开源模型、做原型验证 ──────────► Hugging Face
│
└─ 轻量任务 + 欧洲合规叙事 ───────────► Mistral
```

进阶玩法：**把四家拼成一个路由层**（正是 04 那套 ROUTER 思路的延伸）。下面是一段可直接跑的「国外免费层路由」示例——注意每家只是 `base_url` 和 `model` 不同，其余调用完全统一：

```python
from openai import OpenAI

# 国外免费层路由表：只改 base_url + model，调用方式完全一致
ROUTER = {
    "long_context": {
        "api_key": "你的Gemini_Key",
        "base_url": "https://generativelanguage.googleapis.com/v1beta/openai",
        "model": "gemini-2.5-flash",
    },
    "fast": {
        "api_key": "gsk_xxxxxxxxxxxx",
        "base_url": "https://api.groq.com/openai/v1",
        "model": "llama-3.3-70b-versatile",
    },
    "eu_light": {
        "api_key": "你的Mistral_Key",
        "base_url": "https://api.mistral.ai/v1",
        "model": "mistral-small-latest",
    },
}

def ask(task_type: str, prompt: str) -> str:
    cfg = ROUTER[task_type]
    client = OpenAI(api_key=cfg["api_key"], base_url=cfg["base_url"])
    resp = client.chat.completions.create(
        model=cfg["model"],
        messages=[{"role": "user", "content": prompt}],
    )
    return resp.choices[0].message.content

# 长文档丢给 Gemini，实时问答丢给 Groq
print(ask("long_context", "总结这篇论文的 3 个创新点：{论文}"))
print(ask("fast", "用一句话解释快排"))
```

## 四、四家避坑总览（发之前再看一眼）

1. **别把「免信用卡」当成「无限量」**：四家免费层额度都有限，且配额多按「项目/账号」而非「Key」计——多建 Key 不会叠加额度。
2. **免费档数据条款要读**：Gemini 免费档 prompt 可能用于产品改进；敏感数据优先本地推理（Ollama）或付费档。
3. **额度随时变**：2025-12 Gemini 一夜砍额度就是前车之鉴。所有免费额度写进代码常量 + 进 Git，变动时改一处即可。
4. **延迟不可预测**：Groq 快但峰值限流、HF 冷启动慢、Mistral 1 req/s——生产环境一定做 fallback，别吊死一家。
