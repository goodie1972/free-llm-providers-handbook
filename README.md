# 免费 LLM 弹药库手册 · free-llm-providers-handbook

一个**可长期更新**的「免费大模型 / AI 算力」实战手册。18 篇连载正文全部在这里，公众号和头条只是流量入口，**这个 repo 才是永久沉淀**。

## 这是什么

我从「每月为 AI 花几百块」一路试到「几乎零成本跑通日常开发」，中间踩的坑、试通的站点、算过的账，全写在这 18 篇里。

| 类别 | 说明 | 相关篇目 |
|---|---|---|
| **国内免费** | 大厂送额度、开源社区托管、小众免费站 | 01–04 |

一条主线贯穿全部：**免费养个人，付费养生产**。这句话是本手册所有纪律的浓缩。

## 目录结构

```
/articles/              每篇 markdown 正文（就是上面索引里那些）
/assets/screenshots/    各项目自有截图（本机访问后实拍，不搬别家图）
/assets/images/         自绘图表（Pillow 生成的额度速查表等）
/data/                  免费LLM对照表.xlsx + invites.md（邀请码汇总）
/scripts/               check_md_links.py —— 相对链接校验（提交前请跑）
/.github/               Issue 模板（数据过期 / 新平台推荐 / 站点失效）+ PR 检查清单
README.md               总览 + 篇目索引 + 数据日期 + 更新日志
CONTRIBUTING.md         投稿 / 纠错规范
```

> 提交前请跑一遍 `scripts/check_md_links.py`（在贡献指南里有说明）：**相对链接写错在本地是看不出来的**，
> 典型错法是文件在 `data/` 下却写 `articles/xxx.md`，GitHub 上会 404。

## 怎么贡献

**这个手册最大的敌人是时效。** 你的每一次纠错都比新增一篇更有价值。

- 🐞 **发现过期**（额度变了、站点关了、限流改了）→ 提 [Issue](../../issues)，标题写清 `[过期] 第N篇 - 平台名`
- 📝 **想补充**（新免费平台、新踩坑）→ 提 PR 到 `articles/`，或先开 Issue 讨论
- 🔑 **邀请码失效/更新** → 改 `data/invites.md`，走 PR 由维护者审核
- 📷 **补自有截图** → 放 `assets/screenshots/`，**必须本机实拍，不搬别家图**

详见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 纪律声明

1. **免费养个人、付费养生产**——免费层用于学习、原型、个人脚本；生产/商用请走付费或合规云。
2. **不教违规**——本手册不涉及多账号规避限流、反向工程、转售上游免费额度等违反 ToS 的做法。
3. **敏感数据不丢免费模型**——客户数据、合同、隐私内容请用本地模型或合规云。
4. **所有数据标注核验日期**——未标注日期的数字视为不可信，欢迎提 Issue 补上。
