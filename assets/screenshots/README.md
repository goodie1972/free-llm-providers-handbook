# 截图目录

放本手册各篇里用到的**自有截图**。

## 硬性要求

1. **必须本机实拍**——自己访问平台后截的图，不搬运别家网站的图片（版权 + 时效双重原因）。
2. **不要暴露敏感信息**——提交前检查截图里有没有：
   - 完整的 API key（只露前缀，如 `sk-xxxx...`）
   - 账号邮箱、手机号、实名信息
   - 计费/账单明细里的银行卡信息
3. **自绘图**（如 Pillow 生成的对照表/速查卡）也放本目录，命名带 `-card` 或 `-table` 后缀便于区分。
4. 命名规范：`平台名-用途.png`，例如：
   ```
   unorouter-models-page.png
   siliconflow-quota-page.png
   17-speedcard.png
   ```
